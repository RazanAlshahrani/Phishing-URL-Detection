# Phishing URL Detection Using Machine Learning and Deep Learning

## Project Overview
An academic cybersecurity project focused on detecting phishing websites using Machine Learning (ML) and Deep Learning (DL) techniques. The project analyzes URL-based features to classify websites as legitimate or phishing and compares the performance of different classification models.

## Key Features
- Data preprocessing, including feature selection, duplicate removal, and missing value verification.
- Cleaned the original dataset from 10,000 to 9,581 records.
- Implemented and evaluated four classification models:
  - Decision Tree
  - Random Forest
  - XGBoost
  - Deep Neural Network (DNN)
- Evaluated model performance using Accuracy, Precision, Recall, and F1-score.
- Visualized model performance using comparison charts, confusion matrices, and training curves.

## Model Performance

| Model | Accuracy |
|---|---|
| Decision Tree | 94.94% |
| Random Forest | 96.87% |
| XGBoost | **97.18%** |
| DNN | 95.51% |

XGBoost achieved the highest classification accuracy among the evaluated models.
